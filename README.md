# BUSY — Smart Bus Stop Assistant

Student prototype based on the supplied Level 3 entrepreneurship handouts.

Features:
- Responsive, polished dark/purple/lime visual design
- Browser location permission and nearest sample stop calculation
- Search for places such as school, library and City Centre
- Arrival board and next-bus card
- Local chatbot with broad project/transit question handling
- Privacy and prototype-data messaging
- Sections reflecting problem discovery, value creation, prototyping and testing

Important: bus routes and arrival times are demonstration data. A production version should connect to a trusted transit feed and show source/timestamp.
