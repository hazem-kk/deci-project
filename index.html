04 / THE OPPORTUNITY

Built around a real problem.

The handout’s journey is reflected here: spot a problem → define the user → create value → prototype → test → improve.

⚠

The problem

Passengers can lose time when stop information, routes and arrival details are scattered or unclear.

◉

Primary user

A student or everyday passenger who needs to know where to wait, which bus to choose and what happens next.

✦

The value

Turn a confusing journey into a simple sequence: find → compare → choose → go.

⌁

Prototype & test

Give a tester one task, observe first, record hesitation, then improve the core experience using evidence.

DAY 4 PROTOTYPE MINDSET

Observe first. Improve with evidence.

Don’t add every feature. Make one core experience clearer, safer and easier to use.
